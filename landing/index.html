Retrospective

What We Learned Building This

01JAMstack generation: static delivery + scheduled dynamic content are not opposites — they work together perfectly
02GitHub Actions is the right place for content generation, not serverless functions
03Vercel serverless cannot persist files — keep it for APIs only
04status.json is your single source of truth — if it lies, everything breaks
05Smoke checks before real runs save hours of debugging
0641 deployments to get to green — shipping > perfecting
07AI-assisted development works best with surgical, phase-by-phase prompts
08Every ? on a dashboard is a missing API field, not missing data
